# Support

PARE is an early development project. For installation trouble, unexpected analysis, or questions about supported behavior, search the [README](README.md) and [existing issues](https://github.com/ayushcmd/pare/issues) first. If the answer is missing, open an issue with a minimal synthetic example, your OS, Node.js version, client name and version, and the command or tool that failed.

Please do not paste private prompts, real logs, API keys, or credentials. For suspected security issues, follow [SECURITY.md](SECURITY.md). The project does not yet offer a hosted support service or response-time guarantee.
